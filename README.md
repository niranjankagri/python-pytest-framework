# Python pytest Framework

pytest + Playwright for Python + requests framework for the
[Expand Testing Notes app](https://practice.expandtesting.com/notes/app): one backend with a web UI
and a REST API, tested from both sides.

Work in progress: the framework is being built in small commits; this README grows with it.

## Setup

```
python -m venv .venv
.venv\Scripts\activate          # Windows (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
playwright install chromium firefox webkit
```
